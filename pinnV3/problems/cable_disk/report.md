# Single circular conductor in homogeneous soil

- Identifier: `cable_disk`
- Family: generic 2D conduction, cable-like disk source
- Origin: V3 synthetic verification problem.

The domain is a square soil background with a circular conductor represented as a disk region. The conductor has its own conductivity and uniform volumetric source; the four outer sides prescribe the reference temperature. The JSON is the executable source of geometry, material fields, source and boundary data.
