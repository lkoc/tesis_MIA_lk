# Comunicaciones históricas

Estos archivos se trasladaron desde la raíz para distinguirlos de la evidencia
actual. Se conservaron sus contenidos y nombres. Sus afirmaciones de éxito,
comparación o cierre pertenecen a etapas anteriores y requieren el contraste
documentado en `docs/AUDITORIA_TESIS.md`.

Las rutas relativas dentro de esos textos se interpretaban desde la raíz
original del proyecto. La tesis activa y sus resultados están enlazados en
el README de la raíz; los datos históricos permanecen en `examples/`.
